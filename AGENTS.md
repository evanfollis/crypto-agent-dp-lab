# Crypto Agent DP Lab — archive instructions

## Purpose

This is an immutable lineage repository for a 2025 JAX/E2E-DP trading
prototype. Its engineering is real; its performance thesis was never tested.
The active successor is `https://github.com/evanfollis/atlas`, which uses a
different falsification-first method. Do not present this archive as an active
product, validated study, or Atlas component.

## Commands and boundaries

- `make help` discovers the archive surface; `make check` is the complete gate.
- Preserve source and historical documents as evidence. Correct public
  orientation or security defects, but do not resume feature development here.
- Never promote planned targets, syntax checks, or implementation milestones
  into experimental results. A performance claim requires committed study
  outputs; historical plans and status prose are not evidence.
- Do not copy code into Atlas: there is no repository license, and the methods
  and dependency stacks are intentionally separate. The end-to-end optimization
  methodology and Atlas's falsification-first promotion methodology are
  scientifically incompatible. Public visibility is not a license: seek owner
  authorization before any reuse. Preserve this repository's separate name and
  identity.
- There is no deployment, credential requirement, model runtime, or supported
  release.
- Before setting GitHub `archived=true`, verify the final commit and CI, both
  directions of the Atlas/predecessor lineage links, and truthful description
  and topics. The archive toggle alone is not completion.
- Archive-integrity CI is only a static contract check; it does not execute the
  preserved fast, heavy, GPU, network, or integration suites. State that
  explicitly in any verification claim.

## Definition of done

Archive status and successor links are truthful, `make check` is green, changed
instruction surfaces have a fresh no-cache ADR-0039 release baseline, and
GitHub remains read-only after the final verified commit.
