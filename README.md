# Crypto Agent DP Lab

> **Archived predecessor — research hypothesis not validated.**

This repository preserves a November 2025 engineering prototype for
end-to-end differentiable programming and a neuro-symbolic “Φ-layer” in
systematic crypto research. The JAX implementation is substantive, but the
comparative Phase 2 study was never run and no result artifacts were committed.
The target claims—effect size ≥0.3 and ≥10 bps information-ratio uplift—must
therefore be treated as hypotheses, not findings.

The active successor in this portfolio is
[Atlas](https://github.com/evanfollis/atlas), which follows a different
epistemic design: pre-registration, walk-forward out-of-sample experiments,
typed evidence, explicit falsification decisions, and a code-enforced promotion
gate. This code was not merged into Atlas because its dependency stack and
end-to-end optimization method are materially different.

## What is preserved

- JAX/Equinox Φ-layer and end-to-end pipeline prototypes;
- differentiable portfolio objectives and gradient-health diagnostics;
- experiment plans and implementation notes; and
- the original README and research charter under `docs/`.

No performance result is claimed. “Complete” labels in historical notes refer
to implementation milestones, not experimental validation.

## Archive check

```bash
make check
```

This lightweight check verifies the archive contract and guards against
generated bytecode or renewed current-product claims. The heavy Poetry/JAX
environment is preserved for reproducibility but is not maintained or run in
CI. There is no production deployment, agent runtime, credential requirement,
or supported release.

## Repository map

- `src/crypto_dp/` — preserved prototype source.
